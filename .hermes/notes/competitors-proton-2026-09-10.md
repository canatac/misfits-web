# Compétiteurs — 2026-09-10 (3)

## Proton Mail — Features Clés & Positionnement

**Privacy Architecture** :
- Zero-access encryption (Proton ne peut pas lire vos emails)
- E2E natif entre utilisateurs Proton
- Envoi d'emails protégés par mot de passe vers des destinataires externes (lien sécurisé)
- Open source (audit public)

**Modèle économique** :
- Freemium (1 Go gratuit, 10€/mois pour le pack complet)
- Payant = modèle basé sur la vie privée, pas la revente de données
- Écosystème : Mail + Calendar + Drive + VPN

**Limites** :
- Le chiffrement E2E ne s'applique pas aux emails sortants vers Gmail/Outlook (retour au TLS standard)
- Pas de IMAP/SMTP natif sur les gratuits (Proton Bridge requis)
- Mises à jour lentes selon la communauté Reddit

**Wishlist 2026 (Reddit)** :
- Backups automatiques externes pour les non-Proton users
- Sync vers des calendriers externes
- API ouverte

**Insight pour misfits.ai** :
Proton prouve que la vie privée peut être un business model rentable. Pour misfits :
- **Ne pas essayer de concurrencer Proton sur le chiffrement** (ils sont trop avancés)
- **Se différencier par l'UX** : Proton reste austère, technique
- Opportunité = privacy + modern UI (Superhuman-like) + productivité
- Le mode Screener (Hey) + privacy-by-design = niche inexploitée
