# Compétiteurs — 2026-09-10 (2)

## HEY.com (Basecamp) — Feature Le Plus Différenciante

**The Screener** (roi de la fonction) :
- Chaque nouvel expéditeur passe par une file d'attente avant d'atteindre l'IMbox
- Décision unique : autoriser (IMbox), Feed (newsletters), Paper Trail (reçus/notifications), ou bloquer
- Historique des décisions avec possibilité de revenir en arrière (90 jours de rattrapage)
- Aucune notification à l'expédient — décision privée
- Anti-tracking pixels intégré

**Autres caractéristiques** :
- 100 Go de stockage
- Applications natives toutes plateformes
- Calendrier intégré
- 99$/an
- Pas d'import d'emails existants (repartir de zéro)
- Pas d'API (pas de Zapier, pas d'intégrations tierces)
- Verrouillage fort (changer d'adresse si on quitte Hey)

**Limites identifiées** :
- Interface enfantine (gros boutons coloris)
- Performance lente signalée
- Filtrage limité
- Pas de filtres avancés type recherche booléenne

**Insight pour misfits.ai** :
Le concept de Screener = **permission explicite par expéditeur**. Pour misfits, ce modèle pourrait s'appliquer :
- Mode "Focus" : seuls les contacts prioritaires interrompent
- Feed : newsletters regroupées, pas d'urgence
- Paper Trail : transactionnels sans notification

Différenciation possible : ajouter une couche IA (triage intelligent basé sur le contenu ET l'expéditeur) vs. approche purement manuelle de Hey.
